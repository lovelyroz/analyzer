### Explicit deferred item — accepted at phase lock

CODAL PDF acquisition/extraction is intentionally **deferred** from this framework phase. `src/ingestion/codal/adapter.py::extract_raw_lines_from_pdf()` is therefore a deliberate boundary placeholder and is not a V1 implementation defect.

The locked contract for this phase is:

```text
CODAL PDF / external source
        ↓
CODAL extraction boundary
        ↓
Sequence[RawLineInput]
        ↓
ingest_codal_report()
        ↓
immutable raw/foundation persistence
```

No specific PDF/OCR/table-extraction library is selected or locked in V1. The future operational PDF extraction implementation must plug into this boundary and must not redesign `DATABASE_CONTRACT_V1.3` merely because the extraction technology changes.

**Lock interpretation:** the ingestion framework and boundary are COMPLETE / LOCKED; production CODAL PDF acquisition/extraction is a subsequent operational implementation task.

### Known non-blocking note

DB unique constraint on `fx_rates` remains keyed on `rate_date` for legacy Gregorian rows. Jalali identity is enforced at application upsert level (documented in CHANGE-006). Acceptable for V1.3; a future partial unique index may be added without contract break.
