# Golden Accuracy Audit – Blocked Specification

## Test name

`test_codal_golden_accuracy_audit_blocked`

## Purpose

Validate that persisted CODAL production records match an independently verified expected dataset for the representative production PDF samples.

## Source of truth

Current status: unavailable.

The repository does not contain a valid independent source of truth for CODAL values. No manually verified dataset, official source manifest, tracked expected fixture, or independently audited expected values were found under the documentation, source tree, tests, or sample files.

## Input

Representative production PDFs already used in the repository:

- seo-codal-report (1).pdf
- seo-codal-report (3).pdf
- seo-codal-report (10).pdf
- seo-codal-report (13).pdf

## Expected output

Blocked until an independent source exists.

No Golden dataset may be inferred from:

- production extractor output;
- a second PDF text parser;
- reconstructed PDF text;
- raw rows persisted by the production ingestion pipeline.

## Exact assertions

Once a valid independent dataset is available, the Golden Audit must assert the following:

- company identity;
- CODAL tracking ID;
- report type and title;
- publication datetime;
- financial period;
- version number and current-version state;
- raw-fact item name and code;
- value as exact Decimal;
- explicit NULL vs Decimal("0");
- unit and currency;
- source section, row, and column where available;
- provenance from RawFinancialFact → ReportVersion → Report.

## Independence rationale

The expected values must come from a source that is not generated by the production extractor or any derivative parser. The source must be external, manually or officially verified, and explicitly identifiable as the authoritative expectation.

## Known limitations

At present, the repository does not provide an independent expected dataset, so no financial correctness claim may be made. Any Golden Accuracy Audit would be speculative without such evidence.

## Decision

GOLDEN ACCURACY AUDIT: BLOCKED — INDEPENDENT SOURCE OF TRUTH REQUIRED
